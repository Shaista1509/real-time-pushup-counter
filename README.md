# Real-Time Push-Up Counter using Computer Vision

## Overview
A computer vision application that uses OpenCV and MediaPipe Pose Estimation to count push-ups in real time through a webcam feed.

## Features
- Real-time webcam processing
- Human pose estimation
- Elbow-angle calculation
- Automatic push-up counting
- Live visual feedback

## Technologies
- Python
- OpenCV
- MediaPipe
- NumPy
